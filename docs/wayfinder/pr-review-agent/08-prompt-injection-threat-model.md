# Prompt-injection threat model

Type: wayfinder:grilling
Blocked by: none

## Question
Diffs, PR descriptions, commit messages and code comments are untrusted input that an attacker controls. What can go wrong (suppressing findings, leaking secrets or the system prompt, forged approvals), which guardrails apply (input isolation, structured output, tool restrictions, least-privilege tokens), and how are these attacks included in the evals?
